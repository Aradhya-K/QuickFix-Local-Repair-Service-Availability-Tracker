# QuickFix – Local Repair Service Availability Tracker

QuickFix is a MERN stack web application that connects users with nearby repair and service providers based on service availability and location.

## Features

- Search for nearby repair and service providers
- Book available services
- Track service bookings
- Provider-side service management
- Manage provider availability and bookings
- Responsive web interface

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
